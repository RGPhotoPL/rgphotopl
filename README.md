# RG Photo — website mockup

Static mockup of a new rgphoto.pl: six pages (home, portfolio, oferta, szkolenia,
o mnie, kontakt), dark theme, no CMS and no build dependencies beyond Node.

## Status

This is a mockup, not the live site.

- Prices, training programs, FAQ answers and part of the bio are placeholders.
  The footer says so on every page.
- The contact and sign-up forms validate but do not send anything.
- Older photos load directly from the current rgphoto.pl media library, so they
  need internet access and will break if that library is removed. Newer photos
  (from Instagram) are stored in `site/assets/photos`.

## Layout

```
src/
  build.mjs        page shell (header, footer, photo viewer) + build loop
  photos.mjs       photo catalog: categories, alt text, image helper
  ig-photos.json   sizes of the locally stored photos
  pages/*.mjs      content of each page
site/              the built site — this folder is what gets hosted
  *.html           generated by the build, do not edit by hand
  assets/style.css, assets/main.js   written by hand
  assets/photos/   locally stored photos
```

## Build

```bash
node src/build.mjs
```

Rewrites `site/*.html` from `src/`. Needs Node 18 or newer, no `npm install`.

## Preview

```bash
python -m http.server 4173 --directory site
```

Then open http://localhost:4173/.
